# 09_CHAT · Conversación exportada

- `chat_exportado.json` — datos estructurados (para procesar)
- `chat_exportado.md` — la misma conversación en Markdown (para leer)

Fuente: sesión **MarketAttack** del opencode de la PC, exportada con
`exportar_chat.py`. Los secretos (llaves privadas, tokens, contraseñas) se
sustituyen por `[...]` antes de guardar.

**Nunca subas `opencode.db` ni paquetes `.zip` a este repo**: llevan
conversaciones y datos personales. Para respaldar, usa los scripts del VPS.
